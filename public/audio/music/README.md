# RETRACE — music stems

Seven stems of **one composition**. They are not separate tracks; they are
layers of the same piece, and the game brings them in and out as danger rises.

Everything here is placeholder audio generated by
`node tools/make-placeholder-music.mjs`. Replace any file with real audio and
the game picks it up on next load — **no code changes**.

## The contract

Every stem must match exactly, or they will drift apart:

| | |
|---|---|
| Tempo | **84 BPM** |
| Metre | **4/4** |
| Length | **4 bars** = `11.428571s` (504000 samples @ 44.1 kHz) |
| Key | **A minor** |
| Progression | **Am – F – Dm – E** (one chord per bar) |
| Loop | Must loop seamlessly with no gap or tail click |

Sample rate and channel count are free — the browser resamples on decode. Length
is the one thing that must be right.

## The stems

| File | Enters at | Role |
|---|---|---|
| `ambient.wav` | always | Room tone and pad. Never fully silent. |
| `bass.wav` | 1 | Sub-bass root movement. |
| `percussion.wav` | 2 | Light kit — pulse and hats. |
| `tension.wav` | 3 | Arpeggiated tension synth. |
| `mimic.wav` | 3 | MIMIC's motif. Sparse and recognisable. |
| `chase.wav` | 4 | Full kit and aggressive bass. |
| `hunt.wav` | 5 | Facility emergency layer. Hunt Mode only. |

Intensity runs 0–5. Because every stem plays continuously from a single shared
start time, any combination of them is a valid mix of the same piece — which is
what makes the crossfades inaudible.

## Notes for replacement audio

- **Write them as one arrangement, then export the parts.** Stems bounced from
  one session line up automatically; separately-composed loops usually do not.
- **Leave headroom.** All seven can play at once. Aim for around −12 dBFS peak
  per stem; the game applies its own trims and ducks the master as parts stack.
- **No fades at the file boundaries.** The loop point must be a clean join.
- **Mono is fine** and halves the download.

To change which stem enters at which intensity, edit `STEMS` in
`src/systems/music/manifest.ts` — that table is the only place it is defined.

If a file is missing the game substitutes silence of the correct length rather
than dropping the stem, so the arrangement keeps working. Missing and
wrong-length stems are reported on `music.missingStems` / `music.mismatchedStems`.
